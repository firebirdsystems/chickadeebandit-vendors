# Vendor Recommendations

A [Chickadee Bandit](https://chickadeebandit.com/app-library/vendors) app.

Community-curated directory of local contractors, handymen, landscapers, and service providers. Any member can add a vendor with contact info and a review; others can upvote or add their own.

## Features

- Vendors with contact info and category.
- Reviews from members.
- Upvotes.
- Adults only.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-vendors/releases/latest/download/bundle.json
```
